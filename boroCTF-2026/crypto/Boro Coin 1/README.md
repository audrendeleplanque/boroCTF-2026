## Résolution

### Recherche de la collision (Nonce Reuse)
 
La première étape consiste à analyser les transactions sortantes (où le suspect est l'expéditeur) et à décoder les signatures DER fournies au format hexadécimal pour en extraire les composantes $r$ et $s$.

En inspectant le fichier JSON, on remarque une anomalie :

**Transaction 4** (vers FranklinGothic) :
`signature_der: 304402202cbda85fc21f5e62f94d8378d2dad1a05bc5d5522d5a717f2bdf1df13d558ec70220...`

**Transaction 19** (vers ForeverFlames) :
`signature_der: 304402202cbda85fc21f5e62f94d8378d2dad1a05bc5d5522d5a717f2bdf1df13d558ec70220...`

Les deux signatures possèdent exactement le même composant $r$ :
`r = 2cbda85fc21f5e62f94d8378d2dad1a05bc5d5522d5a717f2bdf1df13d558ec7`

### Mathématiques de l'attaque

Puisque le nonce $k$ a été réutilisé, nous avons le système d'équations suivant :


$$s_1 = k^{-1} (z_1 + d \cdot r) \pmod n$$

$$s_2 = k^{-1} (z_2 + d \cdot r) \pmod n$$

Où :

$z_1, z_2$ sont les hashs respectifs des deux transactions.

$r$ est le composant commun.

$s_1, s_2$ sont les deuxièmes composants des signatures.

$n$ est l'ordre de la courbe secp256k1.

$d$ est la clé privée secrète (ce que l'on cherche !)

Nous pouvons soustraire ces deux équations pour isoler et trouver $k$ :


$$k = \frac{z_1 - z_2}{s_1 - s_2} \pmod n$$

Une fois $k$ trouvé, il suffit de l'injecter dans la première équation pour retrouver la clé privée $d$ :


$$d = \frac{s_1 \cdot k - z_1}{r} \pmod n$$

### Script d'exploitation

Voici le script Python utilisé pour parser les transactions, identifier la collision et calculer la clé privée :

```py
import json
import hashlib

def parse_der(hex_sig):
    """Extrait r et s d'une signature DER hexadécimale."""
    sig_bytes = bytes.fromhex(hex_sig)
    idx = 4
    len_r = sig_bytes[3]
    r = int.from_bytes(sig_bytes[idx:idx+len_r], 'big')
    idx += len_r + 2
    len_s = sig_bytes[idx-1]
    s = int.from_bytes(sig_bytes[idx:idx+len_s], 'big')
    return r, s

# Ordre de la courbe secp256k1
n = 0xFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFEBAAEDCE6AF48A03BBFD25E8CD0364141

# Données des transactions 4 et 19
r = 0x2cbda85fc21f5e62f94d8378d2dad1a05bc5d5522d5a717f2bdf1df13d558ec7

# Transaction 4
msg1 = b"Suspect:FranklinGothic:21.68"
z1 = int(hashlib.sha256(msg1).hexdigest(), 16)
_, s1 = parse_der("304402202cbda85fc21f5e62f94d8378d2dad1a05bc5d5522d5a717f2bdf1df13d558ec702204b2f38c18c2a933f81112350ae048f0162feaaed599f827180944ea3203570de")

# Transaction 19
msg2 = b"Suspect:ForeverFlames:45.46"
z2 = int(hashlib.sha256(msg2).hexdigest(), 16)
_, s2 = parse_der("304402202cbda85fc21f5e62f94d8378d2dad1a05bc5d5522d5a717f2bdf1df13d558ec702207db2d815212aab6b986d0a403b724ad5fd57d2d9e826bf2893e29d9d179d59f3")

# Calcul de k = (z1 - z2) / (s1 - s2) mod n
k = ((z1 - z2) * pow(s1 - s2, -1, n)) % n

# Calcul de d = (s1 * k - z1) / r mod n
d = ((s1 * k - z1) * pow(r, -1, n)) % n

print(f"Clé privée trouvée (d) : {hex(d)[2:]}")
```
